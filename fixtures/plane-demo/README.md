# Plane demo

A planet and a moon in three.js, in TypeScript.

Try, in this order:

1. **Run the tests:** type `npm test` in the Terminal. Two fail: the moon's orbit is off by a quarter turn.
2. **Ask the agent:** press ⌘I and write "fix orbitPosition so the tests pass". It works on its own branch; review its change and accept it.
3. **See it:** open `src/planets.stage.ts` in Stage, or type `npm run dev` for the preview.
4. **Commit:** Git › Commit. Everything here works offline.
